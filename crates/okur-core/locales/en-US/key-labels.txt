# Okur's English key labels, for Manage Key Labels (Settings Center, Keyboard, General): one
# `name<TAB>label<TAB>status` line per key. The name is the key's in a settings file's
# [KeyLabels] section (`Space=0|Space`); the label what the typing echo says for it; the status
# `speak`, `mute`, or `always` (Always Speak, which cannot be muted). An empty label is a group
# of keys that has none of its own (Letters, Numbers, Symbols): muting it silences the
# characters echo of the keys in it.
#
# The keys, labels and statuses are JAWS 2025's defaults as its Manage Key Labels lists them,
# each row read whole (old-pc, 2026-11-06, skills/jaws-reference/scripts/key-labels-walk.ps1):
# Tab and F18 to F24 muted, Control, Shift, Alt (Menu) and Windows always spoken.
